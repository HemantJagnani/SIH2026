# Fare Concept Definition

The system must support extraction of components such as base fare, taxes, fees, discount, and total fare.

For the initial POC, the target price concept is defined as:

> **Total consumer-facing payable one-way economy fare for one adult, excluding optional ancillary purchases.**

This is a project assumption until aligned with the intended CPI methodology.

**Rule:** Never mix base fare from one source with total fare from another without explicit documentation.
